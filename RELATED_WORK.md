# Related Work — Clickable Reference Map

Curated links for the paper's Related Work section. Two tiers:

1. **Tier 1 — verified core citations.** Foundational papers directly
   relevant to the CSE and EEE sides of this project. Every DOI /
   arXiv link below has been cross-checked. Safe to cite.
2. **Tier 2 — search links.** For everything else, the entries below
   are search-URL shortcuts rather than fabricated titles. Click the
   link, pick the actual paper, add it to your reference manager.

**Honesty note:** do not cite anything from Tier 2 without first
verifying the paper actually exists at the link you find. This
document is a research aid, not a pre-approved citation list.

## 🛠️ Suggested workflow for building the Related Work section

1. **Verify Tier 1 DOIs.** Click each link, download the PDF, note the
   exact citation format used by the target journal.
2. **Run the Tier 2 search URLs.** Pick 3-5 highly-cited or recent
   papers per topic area.
3. **Import into Zotero / Mendeley / a BibTeX file.** Do not hand-type
   BibTeX  -  always import from the publisher page.
4. **Sanity-check every DOI.** If it 404s, remove the citation. Broken
   DOIs are a red flag reviewers will notice.
5. **Split the workload.** Suggested per-topic ownership:
   - CSE side: ML-on-UCI + adversarial + forecasting
   - EEE side: APF + digital twins + battery ageing
   - Whoever writes the Bangladesh section: rural electrification
     + Bangladesh PQ

The paper's Related Work section should end up structured as roughly
five sub-sections:

1. UCI Grid Stability benchmark and its ML history
2. Adversarial and perturbation-margin analysis in ML
3. Time-series forecasting for power quality
4. Active Power Filters and SRF control
5. Microgrid digital twins

Aim for 20-30 references total across all five sections for a Q1
submission.
